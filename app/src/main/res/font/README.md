# Typeface

`Geist` by Vercel, in the four weights the type scale uses.

- Regular (400) → `geist_regular.ttf`
- Medium (500) → `geist_medium.ttf`
- SemiBold (600) → `geist_semibold.ttf`
- Bold (700) → `geist_bold.ttf`

Licensed under the SIL Open Font License 1.1: <https://github.com/vercel/geist-font>.
Only the unmodified binaries are vendored; `AppTypeface.kt` references them.
